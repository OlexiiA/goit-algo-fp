## Завдання 1. Однозв’язний список

Кожен вузол містить число й посилання на наступний вузол. Реверс повертає посилання в інший бік. Сортування вставками ставить кожен вузол на своє місце. Об’єднання щоразу бере менше з двох наступних чисел.

## Завдання 2. Дерево Піфагора

Після запуску введіть рівень від `0` до `9` або натисніть Enter для рівня `5`. На рівні `0` є лише один квадрат. Кожен наступний рівень додає по два менші квадрати над попереднім.

## Завдання 3. Алгоритм Дейкстри

Граф записано словником. Ваги ребер невід’ємні. Купа `heapq` допомагає першою брати вершину з найменшою знайденою відстанню. Програма друкує відстань і шлях від `A` до кожної вершини. Наприклад, шлях до `E` іде через `C`, `B` і `D` та має довжину `10`.

## Завдання 4. Бінарна купа

Спочатку `heapq` перетворює список на мінімальну купу. Для елемента з індексом `i` діти стоять на позиціях `2*i + 1` та `2*i + 2`. За цими позиціями будується й малюється дерево.

## Завдання 5. Обходи дерева

DFS використовує стек і йде вглиб, BFS використовує чергу й іде за рівнями. У вікні вузли зафарбовуються по одному від темного до світлого. Порядок також видно в терміналі.

## Завдання 6. Вибір страв

Кожну страву можна взяти один раз. Жадібний алгоритм бере доступні страви з найбільшою кількістю калорій на одиницю вартості. Динамічне програмування зберігає у таблиці найкращий результат для кожної частини меню й бюджету.

При бюджеті `100` жадібний алгоритм набрав `870` калорій за `80`, а динамічне програмування набрало `970` калорій за `100`. У цьому прикладі жадібний вибір пропускає кращу комбінацію.

## Завдання 7. Два кубики

Програма імітує `100 000` кидків. Частку для кожної суми отримуємо, ділячи кількість її появ на загальну кількість кидків. Для теорії перебираємо `36` можливих пар і ділимо кількість пар із потрібною сумою на `36`.

| Сума | Кількість | Монте-Карло | Теорія |

| 2 | 2796 | 2,80% | 2,78% |
| 3 | 5587 | 5,59% | 5,56% |
| 4 | 8300 | 8,30% | 8,33% |
| 5 | 11222 | 11,22% | 11,11% |
| 6 | 13837 | 13,84% | 13,89% |
| 7 | 16456 | 16,46% | 16,67% |
| 8 | 13920 | 13,92% | 13,89% |
| 9 | 11178 | 11,18% | 11,11% |
| 10 | 8303 | 8,30% | 8,33% |
| 11 | 5586 | 5,59% | 5,56% |
| 12 | 2815 | 2,81% | 2,78% |

Симуляція дала значення, близькі до теорії. Найчастіше випала сума `7`, бо її дають шість різних пар. Найбільша різниця з теорією в цьому запуску становила близько `0,21` відсоткового пункту. Невеликі відмінності виникають через випадковість кидків.
